城市公交网络可视化

双方案 · 按需渲染 · 高德瓦片免坐标转换

方案一：plotly Scattermap

直接 Python 生成 HTML，Tab 切换站点/线路/路网三视图。默认 20 条按需渲染，支持 20/50/100/200/全部 一键切换，内置搜索定位。

方案二：folium (Leaflet.js)

Canvas 渲染引擎，874 条线流畅叠加。MarkerCluster 站点聚合、点击线路高亮飞至、悬停弹窗显示线路名+方向。

关键设计：底图统一使用高德瓦片 webrd01.is.autonavi.com（GCJ-02 坐标系），与 API 返回的公交坐标完全一致 → 无需 WGS-84 ↔ GCJ-02 坐标转换，线路自动精准贴合道路，且在国内直连加载，不依赖 VPN。

公交换乘网络搭建

networkx 无向图建模 · 381,501 对线路比较

建模规则 (Space-L 模型)

节点 = 公交线路
每条线路一个独立节点 (L = Line)

边 = 换乘关系
两条线路共享 ≥1 个站点 → 连边
公共站点数 = 边的权重

图类型 = 无向图
换乘是双向的

构建过程

① 遍历 874 条线路，建立站点集合
② 双重循环：874×873÷2 = 381,501 对
③ 检查交集 → nx.add_edge()
④ 导出 GEXF → 可用 Gephi 打开
